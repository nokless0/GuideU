# GuideU

GuideU es un prototipo de aplicación inclusiva desarrollado en **Swift** y **SwiftUI**.

## Objetivo

La aplicación busca apoyar a niños y adolescentes con autismo en la práctica de situaciones sociales cotidianas, principalmente en contextos escolares y familiares.

## Funcionalidades

- Pantalla de bienvenida.
- Pantalla de inicio.
- Reto social interactivo.
- Retroalimentación inmediata.
- Pantalla de resultado.
- Pantalla de ajustes.
- Opción de texto ampliado.

## Accesibilidad

GuideU incorpora distintas herramientas de accesibilidad:

- Accessibility Labels.
- Accessibility Hints.
- Dynamic Type.
- Botones grandes y separados.
- Iconos acompañados de texto.
- Compatibilidad con VoiceOver mediante etiquetas descriptivas.

## Tecnologías

- Swift
- SwiftUI
- Xcode 26.6
- iOS

## Estructura

Los archivos principales del prototipo se encuentran dentro de la carpeta `GuideU`:

- `ContentView.swift`: interfaz, navegación, reto, resultados y ajustes.
- `GuideUApp.swift`: punto de entrada de la aplicación.
